Try an address at example.com to see a server-side error.
“alice”, “admin” and “bob” are taken.
Nothing is really sent anywhere.

What’s happening

  • This is a plain HTML <form>. Without JavaScript it would still submit.
  • required, type="email", minlength and friends become validation rules automatically.
  • data-rules adds anything else, including async server checks (debounced and cancelled as you type).
  • Errors appear on blur, then update as you type. Submitting shows a summary that links to each field.
  • Server errors (HTTP 422) are mapped back onto the right inputs.
