ἀρετή + θέσις

Data-driven web components, without the framework tax.

Arethesis gives server-rendered pages a normalized store, config-driven APIs, live updates, collaborative editing and accessible UI behaviors, in plain HTML and Light DOM custom elements. No virtual DOM, no build-time magic, and zero runtime dependencies.

From the Stoa

Six theses

  1. α′

    Light DOM, real HTML

    Components render into the document, so your CSS and tools just work. Server-rendered islands hydrate in place.

  2. β′

    One normalized store

    Every object lives once under type:id. Edit it anywhere and every view updates.

  3. γ′

    Config-driven APIs

    Map any response shape, paginate with cursors, retry safely, refresh tokens, and batch requests.

  4. δ′

    Live by default

    SSE invalidation, WebSocket channels, Azure Web PubSub, and convergent OT for collaborative text.

  5. ε′

    Accessible behaviors

    Nine keyboard-friendly mixins (sortable, grid navigation, menus, tooltips…) with ARIA built in.

  6. ϛ′

    Secure defaults

    Sanitized HTML and URLs, origin-scoped auth headers, prototype-pollution-safe merges, logout that wipes the cache.
